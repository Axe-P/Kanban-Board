> KanBan Board that allows you to keep track of what needs to be done and what has been accomplished.

### 🏠 [Homepage](https://kanban-board-1nwe.onrender.com)

## Prerequisites

- npm >=5.5.0
- node >=9.3.0

## Install

```sh
npm install
```

## Usage

```sh
npm run build && npm run seed && npm run start:dev
```
